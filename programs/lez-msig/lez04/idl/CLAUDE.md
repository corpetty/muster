# lez04/idl/

`lez_msig.json`: lez-msig's IDL (SPEL IDL v2), GENERATED by `../tools/idl.sh` from `msig_core`
(`../spel.toml` names `Instruction` and `State`). Never edit it by hand: change the types in
`../../core`, then regenerate and commit. It describes the instruction and the state, not the
guest's envelope (`create_key ‖ placement ‖ Instruction`), which IDL v2 cannot express
(`../../README.md`, "IDL").
